# Department branding

The header uses the official **Government of Bihar emblem** universally: public staff login, admin login, signed-in staff and administrators. The browser-tab icon uses the same emblem. The signed-in staff member's registered department name remains below the brand name. It does not present invented department marks, central-ministry logos or programme-specific logos as Bihar departmental logos.

Verified register categories supported: Panchayati Raj, Agriculture, Rural Development and Welfare. The same state emblem is shared across these categories; distinct department-specific artwork has not been verified. The broad Welfare register label is not silently assigned to a particular welfare directorate.

The asset is the unmodified [Bihar emblem SVG](https://upload.wikimedia.org/wikipedia/commons/e/e9/Seal_of_Bihar.svg). The official [Bihar State Electronics Development Corporation website](https://bsedc.bihar.gov.in/en/) identifies this emblem as the Bihar government's official logo. Department references: [Panchayati Raj](https://betastate.bihar.gov.in/biharprd/), [Rural Development](https://betastate.bihar.gov.in/rdd/), [Agriculture](https://dbtagriculture.bihar.gov.in/krishimis/WebPortal/AboutUs.aspx). Avoid confusing Agriculture directorate/programme marks with the department itself.

The SVG is fetched asynchronously from Wikimedia by the browser with no referrer, explicit dimensions on every header. It does not delay login. Only the verified asset hostname is allowed by CSP. Staff identities are never sent in the asset URL.

For multiple registered departments, choosing a department in the attendance form updates the header label. Before selection, registered names are shown together. Data Entry Operator is a job title rather than a verified department; the universal state emblem does not imply a separate departmental identity. Unknown/new and missing departments, administrators and signed-out visitors all use the same Bihar emblem. No staff assignments or historical records are changed.

If verified, distinct official artwork is later supplied, update the department registry rather than substituting a scheme logo or guessing an employer from a job title.
